vue3renderer Architecture

.vue 单文件组件 / 网页 → PNG 截图：常驻浏览器 + 并发限流的渲染管线

调用层

  • • createSnapshotter() 一次配置全局生效
  • • snapshotVue / snapshotUrl / snapshot
  • • 单次调用可临时覆盖截图默认值

渲染管线

  • • .vue → vue3tohtml SSR 内存编译（props 透传）
  • • 网址 goto 加载；vue setContent 加载
  • • 字体等待 + fontFamily 注入回退

运行时

  • • 常驻浏览器，崩溃后自动重启
  • • 信号量并发限流，超出 FIFO 排队
  • • 返回 Buffer，可落盘可直传 HTTP

vue3renderer • Node.js ≥18 • Playwright + vue3tohtml
